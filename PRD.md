# PRD: Boba Picker

## Problem
Students stand at the counter for minutes because they can't decide what to order, and the line builds up behind them.

## Users
Berkeley students who like boba but freeze when they see the menu.

## Must-haves
1. A big "Surprise me" button that picks a random drink, topping and sweetness level.
2. The last 5 picks, so you can go back to one you liked.

## Not now
- Accounts or logins
- Real menus or prices from actual shops
- Ordering or payment
- Saving picks after the page reloads

## Demo script (3 minutes)
1. **The problem (30s):** "You're third in line and still haven't picked."
2. **The app (60s):** tap "Surprise me" a few times and point out the history list.
3. **How we built it (60s):** this PRD and the design doc, pasted into Claude.
4. **What's next (30s):** real shop menus and a "never repeat" option.

## Constraints
- One `index.html` file with CSS and JS inline, and no frameworks
- Works on a phone screen
- Deployed on Vercel from a GitHub repo
- Built in under 15 minutes
